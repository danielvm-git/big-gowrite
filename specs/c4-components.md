## Auth flow

```
Request → Init hooks (api/web/console group)
       → Auth layer (resolve type + credentials)
       → Abuse layer (rate-limit by URL + entity)
       → Action handler (inject $user, $project, $dbForProject, etc.)
       → Response serialization (strip secrets, format)
```

## Module event patterns

| Event | Publishers | Consumers |
|-------|-----------|-----------|
| `users.[userId].create` | Event bus → publisherForEvents | Webhooks, Realtime, Functions triggers |
| `functions.[fnId].executions.[execId].update` | Event bus | Webhooks, Realtime, Functions (next step) |
| `databases.[dbId].collections.[colId].documents.[docId].create` | Event bus | Webhooks, Realtime |
| `proxy.rules.[ruleId].update` | Event bus → publisherForCertificates | Certificates worker |
