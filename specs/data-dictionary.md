## D. Relacionamentos-chave

```
projects 1─* keys / platforms / webhooks / rules / schedules / reports / installations / buckets / functions / sites
projects 1─1 database_{seq} (data-plane) 1─* attributes / indexes / database_{seq} documents
users 1─* sessions / identities / targets / tokens / memberships / presenceLogs
teams 1─* memberships ─* users (roles)
buckets 1─* files (bucket_{seq}) 1─* resourceTokens (resourceId = bucketId:fileId)

reports 1─* insights (reportInternalId); rules 1─1 certificates (domain)
installations 1─* repositories (installationId); repositories ─* vcsComments (vcsCommentLocks)
```
