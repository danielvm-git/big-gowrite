## 5. Key observations

1. **Framework consolidation:** The entire platform is built on the `utopia-php` ecosystem (~40 packages) — utopia-php/http is the framework core. 🟢
2. **Database abstraction:** utopia-php/database v7 provides adapters for MongoDB (default), MariaDB, MySQL, PostgreSQL. 🟢
3. **Background jobs:** 14 workers (builds, certificates, databases, deletes, functions, jobs, mails, messaging, migrations, notifications, screenshots, webhooks) run via utopia-php/queue on Redis. 🟢
4. **Function execution:** appwrite/php-runtimes + open-runtimes/sdk-for-php power the Functions module (Executor in `src/Executor/`). 🟢
5. **Security deps:** php-clamav (antivirus), svg-sanitize, adhocore/jwt, spomky-labs/otphp (2FA). 🟢
