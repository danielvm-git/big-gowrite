## VectorsDB (data-plane template) — G6 resolved

`app/config/collections/vectorsdb.php` defines the per-project VectorsDB collection template (🟢):
- **`embeddings`** — `VAR_VECTOR` column (the embedding vector).
- **`dimension`** — `VAR_INTEGER`, configurable vector dimensionality per collection.
- Plus `name`, `enabled`, `documentSecurity`, `attributes`, `indexes`, `search`, `metadata` (`VAR_OBJECT`), and `databaseId`/`databaseInternalId` link to the parent database.
- Indexes: `_fulltext_search` (fulltext), `_key_name`, `_key_enabled`, `_key_documentSecurity`, `_key_metadata`.
- Backend: PostgreSQL adapter (per `code-analysis.md §3.6`); embeddings produced via `utopia-php/agents`. Contrast with the default/legacy data plane (`databases.php`) which is MongoDB-backed and has no vector column.
