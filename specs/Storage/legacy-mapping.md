## Module path

## Purpose
The Storage module provides object-storage capabilities for Appwrite projects. It manages two resource tiers: **Buckets** (named containers with configurable security, compression, encryption, antivirus, and image-transformation policies) and **Files** (binary objects uploaded to a bucket). Files can be served three ways — as a raw download with Content-Disposition: attachment, as an inline view, or as a server-side transformed image preview. A push-notification endpoint allows internal services to retrieve files using a short-lived JWT rather than standard permission checks.

## Workers & Tasks
None registered by this module. Physical deletion of buckets and files is handled by a separate delete worker triggered via `publisherForDeletes`.

## Key business rules
- 🟢 Creating a bucket also creates a dedicated `bucket_{sequence}` collection with the files schema from `app/config/collections/buckets.php`.
- 🟢 `enabled=false` blocks all end-user access but API keys and admin users can still read/write.
- 🟢 File uploads support chunking via `Content-Range` header; each chunk is tracked with `chunksTotal`/`chunksUploaded`.
- 🟢 Concurrency during chunked uploads is protected by a distributed lock keyed `storage:file:{projectId}:{bucketId}:{fileId}`.
- 🟢 Compression (GZIP or ZSTD) and AES-128-GCM encryption are applied per-file at finalization, but only when `sizeOriginal <= APP_STORAGE_READ_BUFFER`.
- 🟢 Antivirus (ClamAV) scan runs at finalization for local-device files under `APP_LIMIT_ANTIVIRUS` when enabled.
- 🟢 `fileSecurity=true` means per-file permissions are checked; `false` means bucket-level permissions apply to all files.
- 🟢 Permission aggregation converts role groups (e.g. `any`) into the set of individual permission strings they represent.
- 🟢 Image preview requires the `imagick` PHP extension; transformations can be disabled per bucket.
- 🟢 The `/push` endpoint authenticates via a signed JWT (HS256, 1h TTL) instead of session/API key; `internal` flag in JWT selects platform DB instead of project DB.
- 🟢 Download and view both support HTTP Range requests for partial content.
- 🟢 File deletion first removes the physical file from the storage device (or aborts a partial upload), then deletes the DB document, then enqueues a cache-invalidation message.
- 🟡 `totalSize` is always returned as `0` on bucket responses — aggregation likely done out-of-band.
- 🟢 `resourceType` label is `RESOURCE_TYPE_BUCKETS` (value: `'buckets'`).
