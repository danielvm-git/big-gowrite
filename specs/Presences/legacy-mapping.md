## Purpose
The Presences module tracks real-time user presence state within an Appwrite project. Each presence record captures a user's current status (a free-form string), optional arbitrary metadata, a source (rest/graphql), and an expiry timestamp. Records are stored in the `presenceLogs` common collection. The module supports upsert semantics (PUT), selective updates (PATCH), and a TTL-backed in-memory list cache to serve high-frequency reads efficiently. Presence records are soft-expired — they are filtered out on read once `expiresAt` passes but are not automatically deleted.

## Key business rules
- 🟢 `userId` in write operations (upsert, update) is only permitted for API key and privileged users; session callers always operate on their own user identity.
- 🟢 API keys must explicitly provide `userId`; they have no implicit session user.
- 🟢 Default expiry is 15 minutes from now (`+15 * 60` seconds) when not specified on upsert.
- 🟢 Maximum expiry is 30 days in the future (enforced by `DatetimeValidator` bounds).
- 🟢 Expired presences are excluded from GET and LIST responses (checked via `expiresAt < now()`); they are treated as `PRESENCE_NOT_FOUND`.
- 🟢 Permissions default to the owner user's full access; can be explicitly overridden via the `permissions` param.
- 🟢 `listPresences` supports a `ttl` parameter (0–86400 s). When >0, results are cached per project/roles/query using `PresenceState::getListCacheField` / `setListCacheField`, and the response carries `X-Appwrite-Cache: hit|miss`.
- 🟢 The list query always appends `expiresAt > now()` server-side (outside the user-supplied query so it does not pollute the cache key).
- 🟢 `updatePresence` and `deletePresence` accept a `purge` flag that triggers `PresenceState::purgeListCache` to invalidate cached list responses.
- 🟡 The `presenceLogs` collection name suggests a future expansion to log presence events in addition to tracking current state.
- 🟢 `source` field records whether the upsert came from `rest` or `graphql` (detected via `x-appwrite-source` header).
