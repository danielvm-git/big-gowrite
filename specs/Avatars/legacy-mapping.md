## Purpose
The Avatars module provides image-generation and image-proxy endpoints for the Appwrite platform. It serves static avatar assets (browser icons, credit card logos, country flags), generates dynamic images (user initials, QR codes), fetches and resizes remote images and favicons, captures webpage screenshots via a headless browser service, and renders personalized Appwrite Cloud membership cards (front, back, and OG variants). All responses are binary image data; none write to any database. The module caches responses aggressively (30–45 days via `Cache-Control`) and is grouped under the `avatars.read` scope.

## Key business rules
- 🟢 Static avatar sets (browsers, credit-cards, flags) are loaded from `Config::getParam('avatar-{type}')` and validated via `WhiteList`; unknown codes throw `AVATAR_SET_NOT_FOUND` or `AVATAR_NOT_FOUND`.
- 🟢 All static avatar images require the Imagick PHP extension; missing extension throws `GENERAL_SERVER_ERROR`.
- 🟢 Remote URLs (favicon, image, screenshot) are validated against a public-hostname allowlist (`PublicHostname`) and must use `http` or `https` schemes only; private/loopback hosts are rejected.
- 🟢 Favicon fetching follows up to 5 redirects manually (`MAX_REDIRECTS = 5`) to avoid SSRF; each hop is re-validated.
- 🟢 Favicons: SVG icons are sanitized via `SvgSanitizer`; ICO files are returned as-is without Imagick processing; other formats (png, jpg, jpeg) are cropped to 56×56.
- 🟢 The initials avatar derives its background color deterministically from the character codes of the name (5 fixed themes, indexed mod 5), so the same name always gets the same color. Custom hex `background` param overrides this.
- 🟢 Screenshot generation proxies to an internal browser microservice at `_APP_BROWSER_HOST` (default `http://appwrite-browser:3000/v1`); the endpoint accepts rich options (viewport, theme, geolocation, locale, timezone, permissions, user-agent, sleep).
- 🟢 Cloud cards determine tiers: `isEmployee` > `isHero` > `isContributor` (each disables the others); every 100th user by sequence is `isPlatinum`; golden overrides platinum. The card assets are different PNGs per tier.
- 🟡 Cloud cards look up GitHub identity by finding the first session with `provider == 'github'` and refreshing the token if expired. Token refresh uses a retry loop (up to 10 attempts, 500 ms apart) to handle race conditions.
- 🟢 Screenshots are usage-metered via `METRIC_AVATARS_SCREENSHOTS_GENERATED`.
