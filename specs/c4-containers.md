## Container technologies

| Container | Technology | Entry Point |
|-----------|-----------|-------------|
| **Traefik** | Go reverse proxy | Docker compose service |
| **API Server** | PHP 8.5 + Swoole 6 async HTTP | `app/http.php` |
| **Realtime Server** | PHP + Swoole WebSocket | `app/realtime.php` |
| **Workers** | PHP CLI + Swoole (14 scripts) | `bin/worker-*` (12) + `bin/schedule-*`, `bin/queue-*` |
| **Redis** | Redis 7+ | Docker compose service |
| **MongoDB (Platform)** | MongoDB replica set | Docker compose service |
| **MongoDB (Data-plane)** | MongoDB via `utopia-php/database` | Pool of DSNs from env vars |
| **MariaDB** | MariaDB 11+ | Docker compose service |
| **InfluxDB** | InfluxDB 2.x | Docker compose service |
| **Executor** | Docker engine | Spawned by Workers (Functions) |

## Communication patterns

- **API → Workers:** Event-driven via Redis queues. Publishers (`publisherForBuilds`, `publisherForMails`, ...) push messages consumed by specific workers.
- **API → Realtime:** Pub/sub via Redis. API publishes events to channels; Realtime subscribes and fans out to connected WebSocket clients.
- **Workers → Executor:** Docker socket. Builds/Jobs workers spawn executor containers.
